Activity Trace Template
==========================

This is an optional scaffolding template for recording your own per-cycle
bus observations if you choose to simulate `precharge_bus_wrapper.v`
yourself (e.g. using iverilog/vvp) while investigating the module. It is
not pre-filled with any results — you record your own observations here if
you find it useful. Using this template is entirely optional and has no
bearing on how your submission is graded.

Suggested columns:

  cycle | load | dbus[7:0]_hex | valid | num_transitions_from_prev_cycle

Where:
  - cycle: the simulation cycle index
  - load: value of the load signal that cycle (0 or 1)
  - dbus[7:0]_hex: value of dbus that cycle, in hex (e.g. 0x00, 0xA5)
  - valid: value of the valid signal that cycle (0 or 1)
  - num_transitions_from_prev_cycle: number of dbus bit lines that changed
    value compared to the previous cycle (fill in yourself by comparing
    consecutive dbus[7:0]_hex entries)

Example (placeholder rows only — fill in your own values):

cycle | load | dbus[7:0]_hex | valid | num_transitions_from_prev_cycle
------|------|---------------|-------|---------------------------------
  0   |  ?   |     0x??      |   ?   |               -
  1   |  ?   |     0x??      |   ?   |               ?
  2   |  ?   |     0x??      |   ?   |               ?

Add as many rows as needed for the sequence of cycles you observe. Repeat
for multiple `data_in` values / multiple `load` pulses if you want to
compare activity patterns across different transferred data words.
